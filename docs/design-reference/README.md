# Private design reference

The supplied PDF is approved as a layout reference; that is not a blanket licence to redistribute its photographs/text. The current public source tree does not bundle those files. On the implementation machine they are retained privately under `.local/design-reference/` (excluded from Git and Docker builds). The optional authenticated reference preview uses a locally available `property.jpg`; a fresh checkout falls back to marked placeholders. Normal uploaded site media is managed through Admin with its own rights/publication approval.
