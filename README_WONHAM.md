# Wonham Manor House

Self-hosted venue-enquiry platform extending VoxelBooking, licensed AGPL-3.0. Upstream history and notices are preserved. See [upstream provenance](docs/UPSTREAM.md).

Start locally with `START_LOCAL.command` (macOS), `START_LOCAL.bat` (Windows), or `./START_LOCAL.sh` (Linux). Requires running Docker + Compose and Python 3. The launcher prints URLs and creates private random local credentials. No production credentials are supplied.
